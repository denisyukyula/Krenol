# Krenol — Онлайн-гра «Креноль» (Gobang)

Проєкт реалізує мережеву гру двох гравців «Креноль» (п’ять в ряд) на нескінченній дошці за допомогою Flask та SQLite. Підтримуються:

* Створення та приєднання до гри
* Послідовні ходи X та O із валідацією черги та клітинок
* Динамічна дошка, яка розширюється під ходи
* Дострокове завершення гри (здача)
* Збереження результатів у базі даних
* Реплей завершених партій покроково

---

## 🎯 Швидкий старт

### 1. Клонування репозиторію

```bash
git clone https://github.com/yourusername/Krenol.git
cd Krenol
```

### 2. Віртуальне середовище та залежності

```bash
# Windows (PowerShell)
py -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate

# Встановити залежності
py -m pip install -r requirements.txt
```

### 3. Ініціалізація бази даних

```bash
# Створення файлу та таблиць
py src/db/init_db.py
```

### 4. Рестарт бази даних

```bash
# Скидання таблиць
py src/db/reset_db.py
```

### 5. Запуск сервера

```bash
# У корені проєкту, з активованим venv:
py src/main.py
```

* Сервер запуститься на `http://127.0.0.1:5000/`
* Перейдіть у браузері за цим URL, щоб створити або приєднатися до гри.

## ✅ Тестування

Тести написані з використанням `pytest` та покривають:

* Логіку перевірки п’яти в ряд (`tests/test_logic.py`)
* HTTP-маршрути для створення гри, ходів, реплеїв (`tests/test_api.py`)

### Запуск тестів

```bash
# У корені проєкту, з активованим venv:
py -m pytest --maxfail=1 --disable-warnings -q
```

## 📂 Структура проекту

```
Krenol/
├── src/
│   ├── db/
│   │   ├── init_db.py      # ініціалізація схеми
│   │   └── reset_db.py     # очищення та скидання AUTOINCREMENT
│   ├── main.py             # основний сервер на Flask
│   ├── templates/          # Jinja2-шаблони (index, game, replays, replay)
│   └── static/             # CSS-стилі
├── tests/
│   ├── test_logic.py       # юніт-тести логіки
│   └── test_api.py         # інтеграційні тести API
├── requirements.txt        # залежності
└── README.md               # опис проєкту та інструкції
```
